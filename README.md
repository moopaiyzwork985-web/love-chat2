# 💗 love-chat — แชทส่วนตัวสำหรับสองคน

เว็บแชทเรียลไทม์บน Cloudflare Workers (ใช้แผนฟรีได้) ไม่ต้องล็อกอิน ไม่ล็อกไอพี เปิดลิงก์แล้วคุยได้เลย

## Deploy (ประมาณ 2 นาที)

```bash
cd love-chat
npm install
npx wrangler login      # เปิดเบราว์เซอร์ให้ล็อกอิน Cloudflare (ทำครั้งเดียว)
npx wrangler deploy
```

จะได้ลิงก์ประมาณ `https://love-chat.<ชื่อบัญชี>.workers.dev`

## ใช้งาน

1. เปิดลิงก์ ระบบจะสร้างห้องใหม่ให้อัตโนมัติ เช่น `/r/9e5f9923c091`
2. ใส่ชื่อเล่น
3. กด **คัดลอกลิงก์** แล้วส่งให้แฟน ใครเปิดลิงก์ห้องนี้ก็คุยด้วยกันได้ทันที
4. กดปุ่ม "เพิ่มลงหน้าจอโฮม" บนมือถือ จะใช้เหมือนแอปได้เลย

อยากได้ชื่อห้องสวย ๆ ก็พิมพ์เองได้ เช่น `/r/ton-kao-2026` (ใช้ได้ a-z, 0-9, - และ _ ยาว 3–64 ตัว)

## ฟีเจอร์

- ข้อความเรียลไทม์ผ่าน WebSocket หลุดแล้วต่อใหม่ให้เอง
- เก็บข้อความล่าสุด 300 ข้อความ ปิดแล้วเปิดใหม่ก็ยังอยู่
- แสดงว่าอีกฝ่าย "กำลังพิมพ์…" และกี่คนออนไลน์อยู่
- เมนู ⋯ ใช้เปลี่ยนชื่อ หรือล้างแชททั้งหมดได้

## ข้อควรรู้

ไม่มีระบบยืนยันตัวตนตามที่ต้องการ **ใครได้ลิงก์ห้องไปก็อ่านและพิมพ์ได้** ชื่อห้องที่ระบบสุ่มให้เดายาก
แต่ถ้าลิงก์หลุดไปถึงคนอื่น ให้เปลี่ยนไปใช้ห้องใหม่ (เข้าหน้าแรกอีกครั้ง) อย่าส่งรหัสผ่านหรือข้อมูลสำคัญในแชทนี้

ทดสอบในเครื่อง: `npx wrangler dev`
